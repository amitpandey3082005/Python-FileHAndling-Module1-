## 📁 Files Included

| File Name | Description |
| :--- | :--- |
| `01_basic_workflow.py` | Basic steps to open, process, and close a file |
| `02_file_modes_syntax.py` | Overview of file access modes (`r`, `w`, `a`, `x`, etc.) |
| `03_read_methods.py` | Reading files using `read()`, `readline()`, and `readlines()` |
| `04_write_and_append.py` | Writing new content and appending data to existing files |
| `05_with_statement.py` | Safe file handling using context managers (`with open`) |
| `06_tell_and_seek.py` | Moving and checking the file pointer position (`tell()` & `seek()`) |
| `07_exception_handling.py` | Handling `FileNotFoundError` and I/O errors using `try-except` |
| `08_binary_files.py` | Reading and writing binary files (`rb`, `wb`) |
| `09_student_record_project.py` | Mini project demonstrating file handling with student records |
| `10_pathlib_best_practices.py` | Modern file path handling using Python's `pathlib` module |

---

## ▶️ How to Run
1. Make sure **Python 3** is installed on your system.
2. Download or clone this repository.
3. Open your terminal/command prompt in the folder and run any file:
   ```bash
   python 01_basic_workflow.py
   ```
